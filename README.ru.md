# Localzet MQTT

[English documentation](README.md)

Клиент MQTT 3.1.1 и MQTT 5 для Localzet Server 7.

## Состояние и совместимость

Клиент использует API соединений и таймеров Localzet Server 7. Адаптеры MQTT 3.1.1 и MQTT 5 реализуют интерфейс протокола Server. Composer также загружает серверные адаптеры `localzet\\Server\\Protocols\\Mqtt` и `localzet\\Server\\Protocols\\Mqtt5`, поэтому Server 7 распознаёт схемы listener `mqtt://` и `mqtt5://`. Адрес `mqtts://` ниже обозначает TLS-подключение клиента, а не схему listener Server.

Регрессионный набор проверяет частичные кадры, кодирование и декодирование ping-пакетов, а также выбор соединения по схемам `mqtt://` и `mqtts://`. Интеграционный набор запускает временный Mosquitto и проверяет логин/пароль, доставку и подтверждение QoS для MQTT 3.1.1 и MQTT 5 по TCP и TLS, переподключение после перезапуска брокера и восстановление подписки, а также отказ для недоверенного сертификата и несовпадающего имени узла.

## Поддерживаемое поведение

Клиент поддерживает MQTT 3.1.1 и MQTT 5 по TCP и TLS, логин и пароль, публикацию и подписку QoS 0/1/2, подтверждения, переподключение и восстановление подписок. Проверка цепочки TLS-сертификатов и имени узла использует безопасные значения по умолчанию Localzet Server. Для частного центра сертификации передайте PEM-файл через SSL stream context; не отключайте проверку сертификата или имени узла в production.

## Зависимости

- `php`: `>=8.1`
- `localzet/server`: `^7.0`

## Установка

Установите линию релизов для Server 7:

```sh
composer require localzet/mqtt:^1.0
```

Интеграционные проверки подтверждают перечисленные сценарии на Mosquitto, но не совместимость со всеми брокерами. Проверьте работу и доверие к TLS-сертификату на целевой конфигурации.

## Проверки разработки

```sh
composer validate --strict
composer run test
composer run test:broker
composer audit --abandoned=report
```

`test:broker` требует Docker, поднимает временный Mosquitto и создаёт тестовые credentials, самоподписанный сертификат брокера и отдельный недоверенный центр сертификации. Проверяются успешная проверка доверенного сертификата и отказ для недоверенного сертификата и несовпадающего имени узла. Если порты 1883 или 8883 заняты, задайте `MQTT_TEST_PLAIN_PORT` и `MQTT_TEST_TLS_PORT`.

Интеграционный набор проверяет описанные сценарии MQTT 3.1.1 и MQTT 5 на Mosquitto. Он не подтверждает совместимость со всеми брокерами и доверие к сертификатам в конкретном окружении.
